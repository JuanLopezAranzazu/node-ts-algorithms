# Algoritmos con NodeJS y TypeScript

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una API utilizando Node.js y TypeScript para resolver diversos problemas de programación y algoritmos.

## Instrucciones para la ejecución

### Instalar dependencias
Navega al directorio del proyecto y ejecuta el siguiente comando para instalar las dependencias:

```bash
npm install
```

### Ejecutar en modo desarrollo
Para iniciar el proyecto en modo desarrollo, utiliza el siguiente comando:

```bash
npm run dev
```

### Compilar el proyecto
Si deseas compilar el proyecto a JavaScript, ejecuta:

```bash
npm run tsc
```

### Ejecutar en producción
Una vez compilado, puedes ejecutar el proyecto en producción con:

```bash
npm start
```
